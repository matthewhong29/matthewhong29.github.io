02 — Internship Work

Smart Accelerometer Cabinet

My primary intern project: an inventory management and checkout system for the lab's fleet of triaxial accelerometers, replacing a manual sign-out process with a Flask + SQLite web dashboard. This first iteration — internally called the "Trial Run" — is a deliberately software-first build tracking 20 triaxial accelerometers: PIN-based sign-in, direct multi-select checkout/return, and full calibration tracking, all running ahead of the RFID badge and solenoid-locked hardware planned for the full version.

Other Quanta Labs projects remain under NDA and will be added here as they're cleared for public disclosure.

Sign-In & Checkout
  • PIN-based technician sign-in (per-employee PIN, no badge yet)
  • Grid/list toggle with a sensitivity color legend
  • Multi-select checkout and return, no barcode scan step
  • Out-of-cal and already-checked-out units are auto-unselectable
Calibration & Controls
  • Calibration tab: expired / due-in-7 / due-in-30 / current breakdown
  • Controls tab tracks the control accelerometer on each of 12 named shakers
  • Return flow restores prior status (e.g. Shock Only) instead of resetting to Available
Data Sync & Admin
  • Excel master list auto-imports on startup and daily at 8:00 AM
  • Manual "Sync Excel now" button on the Dashboard and Calibration tabs
  • Re-import never overwrites live status on existing units
  • Password-gated Employees tab manages the PIN roster
Dashboard
  • Full inventory view with calibration alerts
  • Live list of everything currently checked out
  • Complete checkout history — who, what, when, and how long
What's Next — Scaled, Locking Cabinet
This Trial Run is the software proof of concept, deliberately scoped without RFID badges, barcode scanning, or physical locking hardware. The planned full version adds RFID fob scanning for physical access control, solenoid-locked drawers tied directly to the checkout system, and LED indicators on each drawer showing unit status at a glance. Beyond inventory tracking, the goal is for project engineers to check real-time accelerometer availability when quoting jobs to customers, so they can immediately see how many units are free and confirm on the spot whether more are available if a customer needs to scale up a test.
